# V3.8.1 Welcome Fix

- Fixed welcome popup buttons: callback queries are now answered exactly once.
- Replying to a photo/video/GIF/document with `/setwelcome <text>` stores both the media and the supplied text.
- `/setwelcome <text>` now updates the text while preserving the existing welcome media.
- Admin-entered text is safely escaped so symbols such as `&` and `<` do not break Telegram HTML parsing.
- Replying to media without command text preserves the existing saved welcome text when the media has no caption.
