# V3.8 — Professional Welcome & Admin Panel

- Professional welcome with image/text/video/GIF/document support.
- Inline buttons: Rules, Verification, FAQ, Admin contact.
- Buttons use Telegram popups and do not flood the group chat.

- Persistent settings in the existing SQLite database.
- Existing verification data and commands are preserved.
